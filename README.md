## 🧰 Herramientas

| Herramienta | Qué hace |
|-------------|----------|
| 📂 **Espacio de trabajo** | Carga tu `.yft` (altura de 1.40 m a 2.30 m) y lee sus datos comparándolo con otros skel. |
| 🩺 **Validador (Doctor)** | Comprueba que el archivo está bien formado; si da "OK", listo para el juego. |
| 🔬 **Diagnóstico avanzado** | Te dice si hay problemas, de qué tipo y **cómo repararlos**. |
| 📄 **Informe técnico** | Informe legible para guardar o pedir soporte. |
| 🔁 **Exportar / Importar** | YDD ↔ XML ↔ YDD (estilo CodeWalker; TRIUM te dice a qué corresponde cada parte). |
| ⚖️ **Comparar** | Enfrenta original vs. resultado para confirmar que nada se rompió. |
| 🦴 **Motor Skel** | Tipo de ped (masculino/femenino/animal), nº de huesos, nombres y jerarquía. |
| 🧬 **Fusionar Skel** | Trasplante/fusión de esqueletos combinando la info de huesos. |
| 🛠️ **Auto Reparar** | Reconstruye y realinea esqueletos dañados; re-injerta huesos borrados. |
| 📐 **Motor Geométrico** | Análisis de la geometría del modelo. |
| 👁️ **Vista 3D** | Visor para confirmar la forma del ped. |
| 🎨 **Texturas** | Inspecciona `.ytd`: difuso/normal/especular, embebidos o externos. |
| 🎯 **Adaptar YDD al Skel** | Adapta un modelo al esqueleto de un `.yft` de destino por nombre, sin tocar la geometría. **Validado byte a byte.** |
| 📏 **Escalar ped completo** | Escalado uniforme de componentes + esqueleto (1.40 m – 2.30 m) sin romper el rig. |
| 🕺 **Convertir a Freemode** | Lleva el ped al esqueleto Freemode (`mp_m` / `mp_f`). |
| ⚒️ **TRIUM Fragua Componentes** | Lleva componentes y texturas de otra ped, re-sincroniza y renombra el `.ymt` sola. |
| 📦 **Stream Creator** | De ped vanilla (4 archivos) a **stream** completo con `_resource.lua` y `peds.meta` listos para FiveM. **100 % fidelidad byte a byte.** |
| 🔐 **Licencia** | Activación **offline atada al equipo**. Sin servidores, sin conexión. |

Interfaz **completa en español e inglés**, cambiable al vuelo sin reiniciar. 🌐
